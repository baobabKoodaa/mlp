Installation instructions:
	1. Find a machine with at least 32GB of RAM.
	2. Create a Numerai account on the Numerai webpage
	3. Set environment variables "NUMERAI_EMAIL" and "NUMERAI_PASSWORD"
	4. Compile required dependency bh_tsne (or run on 64-bit Windows and use the .exe provided in sources)
	5. Use a package manager like Anaconda for other dependencies: Python3, Pandas, scikit-learn & what they require
